# Diversia V2

Architecture du projet DIVERSIA V2 :

- `frontend/` : application React + Vite
- `backend/` : API Express
- `database/` : scripts SQL et seed
- `documentation/` : guides et manuels

## Démarrage

- `npm run dev` : lance le frontend depuis le dossier racine
- `npm run backend` : lance le backend depuis le dossier racine
- `npm run frontend:install` : installe les dépendances frontend
- `npm run backend:install` : installe les dépendances backend

## Structure attendue

Le projet est organisé selon l’architecture professionnelle décrite dans le cahier des charges : `frontend/public`, `frontend/src`, `backend`, `database`, `documentation`.

## Notes

Les dossiers vides de l’architecture contiennent des fichiers `.gitkeep` pour être conservés dans Git.
